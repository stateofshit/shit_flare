Quick Start

  1. Get Gemini API key from Google AI Studio
  2. Copy to "API Keys" tab
  3. Test connection
  4. Set Drive folder path
  5. Click "Index Drive Folder"
  6. Start searching!

Features

  • Semantic Search: Find docs by meaning, not keywords
  • RAG Chat: Ask questions, agent grounds in your docs
  • Batch Indexing: Respects API rate limits
  • Persistent Cache: Embeddings saved to browser (session)
  • OCR Support: Works with scanned PDFs

Architecture

• Colab: File extraction + text processing
• Gemini API: Embeddings + LLM
• Browser: Search UI + chat interface
• Caching: Memory only (no LocalStorage)
