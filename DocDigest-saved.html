VPS Management & Application Deployment

01 System Auditing & Network

  • • Check Listening Ports: ss -tulnp (Detailed with process names) or ss -tuln.
  • • Check Running Services: systemctl list-units --type=service --state=running.
  • • Check Public IP: curl ifconfig.me or curl icanhazip.com.
  • • Internal Network Scan: nmap -sV <your-public-ip> (Simulates external perspective).
  • • Service Status: systemctl status <nginx|ssh|apache2>.

02 Firewall & Security

  • • Check UFW Status: sudo ufw status verbose.
  • • Check IPTables: sudo iptables -L -n -v.
  • • Hardening SSH:

    Disable password auth: Edit /etc/ssh/sshd_config → PasswordAuthentication no

    Restart SSH: sudo systemctl restart ssh
  • • Brute Force Protection: sudo apt install fail2ban -y.

03 Nginx & Domain Management

  • • Test Configuration: sudo nginx -t.
  • • Reload Nginx: sudo systemctl reload nginx.
  • •
    Reverse Proxy Template: 
    location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

04 SSL & Certbot

  • • Generate Certificate: sudo certbot --nginx -d domain.com -d www.domain.com.
  • • Force HTTPS: Certbot handles automatic redirects and configuration.
